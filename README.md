## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
```bash
git clone https://github.com/bharat-poojari/Bharat-Portfolio.git
````

### 2️⃣ Navigate into the folder

```bash
cd Bharat-Portfolio
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Run the development server

```bash
npm run dev
```
